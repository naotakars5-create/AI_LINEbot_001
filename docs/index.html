何が変わったか

連邦民間機関においてDeepSeek製品だけでなく、同技術を基盤としたサードパーティ製サービスまで排除対象を拡大した点。

FASCSA連邦調達サプライチェーン安全法の略で、安全保障上のリスクがあるIT製品の調達を制限する米国法。
