Introducing Tool Retrieval in the Gemini API

Gemini APIへのツール検索機能（Tool Retrieval）の導入

Gemini APIにツールをオンデマンド取得する「Tool Retrieval」が追加された。

大量のツール定義を一度に送らず、必要な時だけスキーマを読み込んでトークンを削減する。

サーバーとクライアントの両方の検索に対応し、Gemini 3.6以降で利用できる。

何が変わったか

リクエストごとにすべてのツール定義（パラメータ定義）を送信する必要がなくなり、モデルが必要としたタイミングで動的に読み込めるようになった点。

Tool Retrieval多数のツール定義を事前に読み込まず、必要なときだけ検索・取得してトークン数や遅延を抑える技術。
Interactions APIGeminiモデルとの会話、ツール呼び出し、状態管理などを一元的に扱うためのAPI。

Windows PCを複数台接続して1個のAI処理クラスターとして扱う機能「RDMA over USB4」をMicrosoftが発表、USBケーブルのみで接続可能で専用機材不要

Microsoft、複数台のWindows PCをUSB4ケーブルで直結しAIクラスター化する「RDMA over USB4」を発表

Microsoftは複数台のWindows PCをUSB4ケーブルで直結しAIクラスター化する機能を発表した。

高価なネットワーク機器なしでメモリやGPU能力を共有し、大規模AIモデルを高速実行できる。

イーサネット経由より大幅に低レイテンシ化を実現しており、開発者向けプレビュー版を公開予定。

何が変わったか

高価な専用ネットワーク機器（RDMA対応NIC等）を使用せず、市販のUSB4ケーブルのみでPC間を直結して高速なRDMA通信を行えるようになった点。

RDMA (Remote Direct Memory Access)CPUを介さずネットワーク上の他PCのメモリに直接アクセスして高速データ転送を行う技術。
USB4最大40Gbps〜80Gbpsの超高速転送や複数プロトコル伝送に対応したUSB規格。
